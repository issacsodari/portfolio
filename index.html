Microsoft Payroll Application & Azure Infrastructure Operations

Role: Cloud Operations & Automation Specialist | Client: Microsoft | Timeline: Nov 2021 – Oct 2024

Employer Tata Consultancy Services (TCS)

Provided L2 production support and Azure infrastructure operations for Microsoft's business-critical payroll platform, which runs on Azure Virtual Machines, Azure networking, Azure SQL Database, Azure Data Factory (ADF), and Azure WebJobs. Maintained 99.9% uptime across monthly payroll calculation runs.

Technical Responsibilities:

  • Azure IaaS Administration: Managed fleet of Azure VMs: health monitoring, start/stop/restart operations, OS disk performance troubleshooting, and connectivity triage. Maintained Storage Accounts, Blob containers, VNets, subnets, and NSG rules.
  • Private Networking & Security: Configured Private Endpoints and Private DNS zones to secure communication between application tiers and Azure SQL Database, isolating backend traffic from the public internet.
  • Bicep Provisioning & Patch Compliance: Deployed and updated cloud resources from Bicep templates using Azure CLI and PowerShell; managed monthly VM OS security patch compliance via Azure Update Manager.
  • Backup & Disaster Recovery: Monitored daily Azure Backup jobs in Recovery Services Vaults, executed monthly file and full-VM restore tests, and ran bi-annual Azure Site Recovery (ASR) DR drills to enforce RTO and RPO compliance.
  • Observability & KQL: Investigated production alerts from Azure Monitor, VM Insights, Service Health, and Action Groups. Queried Log Analytics using KQL to correlate application exceptions and isolated network drops with Network Watcher.
  • Sev 1 & Sev 2 Incident Management: Handled payroll incidents end to end in Microsoft Dynamics 365. Troubleshot payroll batch failures alongside ADF, WebJobs, and SQL teams, joining emergency major incident bridges and driving RCA.
  • PowerShell Automation: Authored daily automated health check scripts (Get-AzVM -Status, Get-AzRecoveryServicesBackupJob, Get-AzMetric) that reduced manual shift handoff preparation from 45 minutes to under 2 minutes.

Project 2 • Enterprise IAM & M365

Azure Cloud Administration, IAM & Microsoft 365 Administration

Role: Global Azure Cloud Administrator – L2 | Client: Microsoft (MCAPS Trust Protection Systems) | Timeline: Nov 2024 – Jul 2026

Employer Tata Consultancy Services (TCS)

Delivered L2 administration of Azure, Microsoft Entra ID, Microsoft 365, and Exchange Online for a global Microsoft business group, overseeing security monitoring, identity lifecycle governance, and compliance operations.

Technical Responsibilities:

  • Identity Lifecycle Governance: Administered Microsoft Entra ID user accounts, security groups, and guest (B2B) accounts across Joiner, Mover, and Leaver (JML) workflows. Enforced least-privilege RBAC role assignments.
  • Privileged Identity Management (PIM): Governed high-privilege directory and Azure subscription role activations with mandatory justification, ticket numbers, and automated expiration windows; conducted quarterly Access Reviews.
  • Authentication & Conditional Access Triage: Diagnosed sign-in failures, MFA method resets, and Conditional Access policy blocks using Entra ID Sign-in logs, Audit logs, and the What If diagnostic tool.
  • Security & Threat Investigation: Reviewed risky users and risky sign-ins flagged by Entra ID Protection and Microsoft Defender; revoked active sessions and enforced password resets on compromised accounts.
  • Exchange Online Administration: Managed user, shared, and resource mailboxes, distribution groups, and mail flow rules. Assigned Full Access and Send As permissions; traced email delivery and quarantined messages using Message Trace and EOP.
  • Service Tree Mapping: Leveraged Microsoft Service Tree to trace service dependencies and identify business component owners, ensuring incident escalations and change requests reached appropriate teams.
  • Graph PowerShell Automation: Built automation scripts for bulk onboarding/offboarding, license auditing, and mailbox permission CSV reporting using modern Microsoft Graph PowerShell (Get-MgUser, Get-MgUserLicenseDetail, Get-MailboxPermission).
Technologies & Toolset:
Microsoft Entra ID Privileged Identity Management (PIM) Conditional Access Multi-Factor Authentication (MFA) Microsoft 365 Admin Center Exchange Online & Mail Flow Message Trace & EOP Microsoft Intune Microsoft Graph PowerShell Microsoft Service Tree
