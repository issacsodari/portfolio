## 🌟 Platform Features & Architecture

This platform is engineered as a zero-dependency, ultra-fast modern web application built with **HTML5, Tailwind CSS, Lucide Icons, and Vanilla ES6+ Modular JavaScript**:

1. **Recruiter 30-Second Quick Scan Banner:** Immediate availability status, key stats, verified credentials, and ATS resume quick-jump.
2. **Global Search Engine (`Ctrl+K`):** Instant search modal querying across skills, deep-dive learning modules, troubleshooting runbooks, command reference, and practical labs.
3. **Technical Skills Library (Categories A–G):** 85 structured cloud skills covering Azure Infrastructure, Monitoring, IAM, M365, Automation, Networking, and ITSM.
4. **Dedicated Learning Hub:** Multi-part deep-dive modules (Introduction, Architecture, Enterprise Configurations, Practical Implementation, Real-World Scenarios, Interview Questions, and Quick Revision notes).
5. **Production Troubleshooting Runbooks:** Practical incident triage guides covering VM RDP failure, High CPU spikes, Disk space exhaustion, NSG blocking, VNet Peering routing drops, Storage 403 Forbidden, Entra ID Conditional Access blocks (Error 53003), Exchange NDR 550, and Sev 1 incident bridge operations.
6. **Command Reference Library:** Searchable reference for 50+ commands across Azure CLI (`az`), Azure PowerShell (`Az`), Microsoft Graph (`Microsoft.Graph`), Exchange Online, and Kusto Query Language (KQL) with 1-click copy-to-clipboard.
7. **Hands-on Practical Labs:** 15 enterprise labs with architecture descriptions, step-by-step CLI/PowerShell commands, verification tests, and troubleshooting tips.
8. **Interview Preparation Platform:** Categorized dual-answer questions (Quick Summary + Senior Engineer Depth), practical enterprise reasoning, and an interactive 10-question technical quiz with instant feedback.
9. **Interactive Learning Dashboard:** Persistent browser tracking (`localStorage`) for completed topics, bookmarks, daily goals, and progress completion percentages.
10. **ATS-Friendly Recruiter Resume:** Printable view with `@media print` styling that formats cleanly for saving as a PDF.
11. **Dark & Light Mode:** Built-in Microsoft Azure navy dark theme and crisp enterprise light theme.

## 🚀 How to Run Locally

Because the project is built with modern web standards and client-side CDN integrations, **no `npm install` or compilation is required**.

### Option 1: Direct File Launch
Simply double-click `index.html` in Windows Explorer or open it directly in any modern browser (Chrome, Edge, Firefox, Safari).

## 🌐 How to Publish to GitHub Pages

1. Initialize git in the portfolio folder and push to your GitHub repository:
   ```powershell
   cd c:\Users\swarn\WorkSpace\portfolio
   git init
   git remote add origin https://github.com/issacsodari/portfolio.git
   git add .
   git commit -m "Initial commit: Complete Azure Cloud Administrator Portfolio & Learning Platform"
   git branch -M main
   git push -u origin main
   ```

2. Enable **GitHub Pages**:
   - Go to your repository on GitHub: `https://github.com/issacsodari/portfolio`.
   - Click **Settings** > **Pages** (under Code and automation in the left sidebar).
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and root `/ (root)`, then click **Save**.
   - Within 60 seconds, your site will be live at:
     **`https://issacsodari.github.io/portfolio/`**
